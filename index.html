Arrow — Pattern & Scoring System

C# · Unity Input System

Goal: reward precise, fast input without punishing small timing errors too harshly.

How it was built: each pattern is a list of arrow objects, and each arrow holds an index for the direction it points. The player's input also maps to an index for the key pressed. When the input matches the first arrow in the list, that arrow counts as correctly pressed and the game moves on to the next one. Difficulty increases as more patterns are completed successfully.

A Bridge Too Dumb — Object Freezing & Outline Shader

C# · Runtime Physics & Shader

Goal: let players build bridges in real time with visual feedback.

How it was built: using Rigidbody physics, when one object gets close enough to another, they snap together and freeze in place, creating the illusion that they're connected. While an object is within snapping range, its outline turns green to signal that it can be attached.

VortexGear — Ship movility mechanics test

C# · Runtime Physics & Input System

Goal: build ship-control mechanics with a good game feel.

How it was built: a quick, basic prototype using Rigidbody physics and Unity's New Input System. Effects like a full-screen speed shader and camera shake were added to sell the feeling of speed.
