Arrow — Pattern & Scoring System

C# · Unity Input System

Goal: reward precise, fast input without punishing small timing errors too harshly.

How it was built: Each pattern corresponds to a list of objects. Each object (arrow) contains an index indicating the direction it points. The player's input also contains indices indicating the key pressed. If the arrow index and the input match, the first arrow in the list is considered pressed correctly. The game then continues with the following arrows. The difficulty increases as more patterns are completed correctly.

A Bridge Too Dumb — Object Freezing & Outline Shader

C# · Runtime Physics & Shader

Goal: let players build bridges in real time with visual feedback.

How it was built: Used Rigidbody. When a object is too close to another object they snap and freeze so it gives the ilusion that they are connected, when the object is able to snap, the outline is colored green to indicate it.
